GaussManinResurgence.local_singular — Method

Local solution at the singular point σj: Lj(z) = H(z-σj) exp(xj log(z-σj)), H holomorphic with H(0) = 1 (principal branch of log). Needs |z-σj| < dist to other letters. Solves k hk - [xj, hk] = Σm Am h{k-1-m} order by order.

source

GaussManinResurgence.monodromy_factor — Method

Monodromy factor M with L^γ(z0) = L(z0) · M for the loop around σi based at z0 (straight segment z0 → σi, one turn, back). Returns (M, C), C the regularised value at σ_i.
