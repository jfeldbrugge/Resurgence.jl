Expansion(x, f₀, μ, Ts)

Resurgence.BorelPadeResum — Method
BorelPadeResum(trans, k; ϵ = 0.01)

Borel-Padé sum of the series Σₘ Tₘ/kᵐ (trans.Ts): the Borel transform Φ(t) = Σₘ Tₘ tᵐ/m! is replaced by its diagonal Padé approximant and Laplace transformed, k ∫₀^∞ e^{-kt} Φ(t) dt, which reproduces Σₘ Tₘ/kᵐ term by term. When a Padé pole lies within an angle ϵ of the positive real axis (a Stokes line), the ray is rotated upwards, halfway to the next pole direction (at most π/4): the lateral sum from above. Returns (integral, error).

Resurgence._remainder — Method

Approximation of the remainder RN^(j)(κ) with L levels of re-expansion. The re-expanded series of the adjacent saddle point l is truncated at Nl = max(0, N - ⌈scale |F_jl|⌉), with scale = |k| of the top level (Olde Daalhuis 1998, eq. (4.18)). The re-expanded series contributes a closed-form sum of level-one hyperterminants; for L > 1 the remainder of saddle l, one level deeper, is integrated against the level-one kernel,

w^{-N} ∫_0^∞ v^{N-1} e^{-v}/(1 - v/w) R_{N_l}^(l)(v/F) dv,       w = κF.

Resurgence.frobenius_gauge — Method
frobenius_gauge(Σ, Rs, j, z; K = 40)

Holomorphic factor G(z) of the Frobenius normal form Y(t) = G(t) (t - σj)^{Rj} C of the Fuchsian system at σj, with G(σj) = I. With A(t) = Rj/(t - σj) + Σm Am (t - σj)^m, the coefficients of G(t) = Σm Gm (t - σj)^m solve m Gm + Gm Rj - Rj Gm = Σ{i<m} Ai G{m-1-i}, which is uniquely solvable when no two eigenvalues of Rj differ by a positive integer (e.g. Rj nilpotent). Needs |z - σj| < distance from σj to the other letters.

Resurgence.hyperasymptotic — Method
hyperasymptotic(transseries, n, Σ, K, k; level = 1, component = 1, N = nothing,
                truncation = :daalhuis, rtol = 1e-10)

Hyperasymptotic approximation of the integral,

Σ_j n_j e^{ikλ_j} (ik)^{μ_j} [ Σ_{m<N_j} T_m^(j)/k^m + R_{N_j}^(j)(k) ],

with the remainders re-expanded level times in terms of the series of the adjacent saddle points (level = 0 is the superasymptotic approximation). transseries is the vector of Expansions from transseries (a named tuple (λ, μ, T) per saddle point is accepted as well; component selects a row when T is a matrix), n from relevance, Σ are the Borel singularities and K the Stokes constants of stokes_constants (package convention K[l, j] = K_{l←j}, computed with the normalisation of transseries).

Truncation (truncation = :daalhuis, the default): the series of saddle j is truncated at Nj = ⌈αj^(level) |k|⌉, with αj^(level) the shortest path of level + 1 steps from tj in the adjacency graph (path_lengths), and every re-expanded series at Nchild = max(0, Nparent - ⌈|k Fedge|⌉). truncation = :uniform uses Nj = ⌈(level + 1)|k| Fj⌉ instead, with Fj the distance to the nearest adjacent singularity. Pass a vector N to set the top-level truncations directly.

Level one is evaluated in closed form; level L nests L - 1 quadratures, so levels beyond 2 become expensive. The relation used assumes μ_j = 0 (non-degenerate saddle points in the normalisation of the package). Returns (value, N, terms) with terms[j] the contribution of saddle j.

Resurgence.hyperterminant — Method
hyperterminant(M, w; method = :closed, rtol = 1e-10)

Normalised level-one hyperterminant

h(M, w) = Γ(M)⁻¹ ∫_0^∞ v^{M-1} e^{-v} / (1 - v/w) dv = -w e^{-w} E_M(-w),       M > 0,

so that h → 1 for |w| → ∞, with EM the generalised exponential integral (method = :closed, the default) or by quadrature (method = :quadrature). The integral has a pole at v = w when w lies on the positive real axis (a Stokes line), the branch cut of EM(-w): off the cut h is the analytic continuation from either side, and exactly on it the average of both sides (the median value) is returned.

Resurgence.morse_normalisation — Method
morse_normalisation(H; atol = 1e-8)

Leading coefficient T0 = 1/√det H of the series of a critical point with Hessian H. For a complex critical point, the principal branch is used. For a real critical point with Morse index ν (the number of negative eigenvalues of H), the branch is fixed by stationary phase, √det H = e^{iπν/2} √|det H|, such that T0 = (-i)^ν / √|det H| is the contribution of the real critical point to the integral: real critical points then enter with intersection number n = +1 (see morse_orientation). For det H < 0 the principal branch would be ambiguous, as it depends on the sign of the rounding error in the imaginary part of det H.

source
Resurgence.morse_orientation — Method
morse_orientation(H, T0; atol = 1e-6) -> Int

Intersection number n = ±1 of a real non-degenerate critical point in the Euclidean integral, relative to the normalisation T0 (leading coefficient of its series, 1/√det H in the package). Stationary phase gives the contribution e^{-iπν/2}/√|det H| (ν the Morse index), so n = e^{-iπν/2}/(√|det H| T0).

Resurgence.path_lengths — Method
path_lengths(Σ, K, steps)

Olde Daalhuis' numbers αj^(steps-1): for every Borel singularity tj, the length of the shortest path of steps steps tj → t{j0} → … in the adjacency graph (edges j → l with K[l, j] ≠ 0, revisits allowed). For steps = 1 this is the distance to the nearest adjacent singularity (singulants). The minimal remainder at hyperasymptotic level L is of the order e^{-α^(L) |k|}, attained for Nj = α_j^(L) |k| (Proc. R. Soc. Lond. A 454 (1998) 1, eqs. (2.14), (4.15)).

Resurgence.plotStokesGraphGM — Method
plotStokesGraphGM(Σ, K; plotRange = nothing, from = :column, orient = :positive, atol = 1e-6, ...)

Plot the Stokes graph in the Borel plane: the singularities Σ as points and one edge for every adjacent pair, labelled by its Stokes constant. K is antisymmetric (K{i←j} = -K{j←i}), so an edge carries a single number once it is given a direction.

  • from = :column reads K[j, i] as K{j←i}, the constant of the edge i → j (convention of `stokesconstants);from = :rowreads K[i, j] as the edge i → j (as infindStokesConstants`).
  • orient = :positive: each edge is drawn as an arrow i → j along the direction in which the Stokes constant is positive, labelled by |K|. The sign is carried by the arrow.
  • orient = :index: each edge points from the lower to the higher index, i → j with i < j. It is labelled by the signed constant, and the colour gives the sign (poscolor, negcolor; cplxcolor when the constant is not real).
  • The line width grows with |K|. A warning is issued if K is not antisymmetric within atol.
  • Each singularity is labelled in the widest angular gap between its edges, so the labels do not overlap the graph.
  • plotRange = nothing fits the limits to Σ; a number r gives the square [-r, r]².

Returns (fig, ax).

Resurgence.southeast — Method
southeast(Σ, K, n0; convention = :package, include_vertical = false, verbose = false, atol = 1e-9)

Apply the South-East rule to the Borel singularities Σ (tj = -iλj), the Stokes constants K and the intersection numbers n0 at θ = π/2 (see initial_intersection_numbers); returns the intersection numbers n at θ = 0, i.e. Ψ = Σj nj Ψ^(j).

  • convention = :package: K[l, j] as returned by stokes_constants (update nl -= nj K[l, j]); convention = :paper: K[l, j] = Klj of the paper (update nl += nj K[l, j]). For the output of findStokesConstants (transposed with respect to `stokesconstants) passtranspose(K)`.
  • K is rounded to integers (with a warning when it is not close to integers).
  • A warning is issued when a firing edge is horizontal (the integral lies on a Stokes line, where the jump is only half) or when two firing edges at the same angle share a saddle.

For f unbounded from below the Euclidean integral diverges; n0 must then be supplied by other means (e.g. from a regulated exponent f + ε‖x‖⁴, see Aniceto, Feldbrugge & Howls).

Resurgence.stokes_constant — Method

Stokes constant K{j←i} for the Laplace contour of saddle i crossing the Borel singularity σj, from the keyhole contour around σj. vs[a] is the leading vector of Φ̂a; by default it is T0[a] times the eigenvector of Ra with unit first entry. For integer Stokes constants, T0[a] should be the normalisation of the asymptotic series of saddle a, T0[a] = 1/√det H(xa), ordered like Σ. Returns (K, S, relresidual) with S = U₋⁻¹U₊ the keyhole holonomy and relresidual the part of the jump not proportional to Φ̂_j (should be ≈ 0).

method = :hyperlog evaluates the free hyperlogarithm series truncated at weight N (giving access to the weight expansion); method = :matrix transports the matrices directly, with no weight truncation (N is then ignored). Use :matrix for more than a few saddles. method = :loop uses the single-loop formula U₊ - U₋ = Uarc₊ (I - L) Ustem: the two paths share their stem and differ by one loop around σj, whose monodromy L = G(p) e^{2πi Rj} G(p)⁻¹ follows from the Frobenius normal form at σj (`localmonodromy`). It avoids subtracting two transported propagators; the second return value is then L instead of the keyhole holonomy.

N is either an integer (used as given) or :auto. With :auto (hyperlog only) the smallest N with certified truncation error |KN - K| < 1/2 is used (`sufficientN, keywordsNmax,sharp,aposteriori), so thatround(K)is exact when the Stokes constants are integers. The bound assumes nilpotent residues (ρ = 0, the package convention). If it certifies no N ≤ Nmax, or the certified N would need more thanmaxwordswords (about n^N for n letters), it falls back tostokesconstantincrement` within that budget.

Resurgence.superasymptotic — Method
superasymptotic(transseries, n, Σ, K, k; component = 1, truncation = :singulant)

Superasymptotic approximation Σj nj e^{ikλj} (ik)^{μj} Σ{m<Nj} Tm^(j)/k^m, with the Expansions transseries from transseries (a named tuple (λ, μ, T) per saddle point is accepted as well; component selects a row when T is a matrix), intersection numbers n (from relevance), Borel singularities Σ and Stokes constants K (`stokesconstants` convention, only adjacency K[l, j] ≠ 0 is used).

truncation: :singulant truncates at Nj = ⌈|k| Fj⌉, :smallest at the smallest term of each series, an Int at a fixed order (fixed-order asymptotics, for comparison).

Resurgence.trace_contributions — Method

Weight-resolved tr((Ti - I)(Tj - I)): entry r-1 is the total-weight-r contribution Σ{p=1}^{r-1} tr(Di[p+1] Dj[r-p+1]), r = 2..N, with Di the weight pieces of Ti (e.g. from `monodromypieces`). The leading entry is (2πi)² tr(Ri Rj).

Resurgence.transseries — Method
transseries(f, GM, M; saddles = nothing, component = 1)

Asymptotic series of every saddle point to order M, ordered as GM.λs, as a vector of Expansions (x, f₀, μ, Ts): the critical point x, the Borel singularity f₀ = t = -iλ, the exponent μ and the coefficients Ts of the series of the basis element component of the Gauss-Manin system (1 = Ψ itself). The series are normalised such that the leading coefficient of the first component is T0 = 1/√det H, with the branch fixed by morse_normalisation (principal branch for complex critical points, Morse convention for real ones, so that real critical points enter with n = +1). For component = 1, T0 = Ts[1]: pass the same T0 to stokes_constants and relevance. The critical points are found with findAllSaddles unless saddles is given.
